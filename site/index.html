      features.md

      Type right away. Alt avoids Ctrl clashes.

      Open a file and start typing; editing is non-modal. Most shortcuts use Alt because apps that host a terminal can intercept Ctrl before sanitty sees it. Find (Ctrl+F), save (Ctrl+S), undo/redo (Ctrl+Z, Ctrl+Shift+Z) and the clipboard stay on Ctrl, and F1, F2, F3 and F8 handle help, rename, find next and problems.

      Search EverywhereAlt+K

      Files, actions, workspace symbols, text and problems in one filterable list. Jump directly to a file, symbol or line with Alt+N, Alt+S and Alt+G. Recent files sit on Alt+E and the project tree on Alt+1.

      Language serversAlt+B

      Definition, implementation, usages, rename (F2), problems (Alt+6 and F8), quick docs (Alt+H), formatting and completion, with auto-imports when the server supplies them. Uses ty and ruff for Python, rust-analyzer for Rust, and tsc (TypeScript 7+) or typescript-language-server for TypeScript and JavaScript.

      Find and replaceCtrl+F

      Find in the current file with Ctrl+F, step through matches with F3, replace with Alt+R, or search the whole workspace with Alt+F.

      Multi-caret editingAlt+A

      Add carets above and below (Alt+Up / Alt+Down), at the next or every occurrence of a word, or at the ends of selected lines. Typing, deleting or commenting at all of them is one undo step.

      Highlighting

      Tree-sitter colours your code and reparses only what changed, except in TypeScript. CSV and TSV files get a colour per column, structure checks and the active column name in the top line, and style files show a swatch beside each colour value.

      Your own keys

      Override any default binding in keymap.toml and configure tab size, Python servers or database row limits in settings.toml.

      views.md

      Three views beside the editor

      Switch to git review, your project databases or a shell without leaving the terminal, then press the same key to return to your code.

      ReviewAlt+9

      Inspect uncommitted changes, this branch against main, one or more commits, or an open GitHub pull request through gh. Toggle side-by-side or inline diffs in syntax colours, leave comments on lines and ranges, mark files viewed, and copy the review as Markdown. Comments stay saved between runs, outside the project.

      DatabaseAlt+8

      PostgreSQL, MySQL/MariaDB and SQLite, with connections found in docker compose or configured in .sanitty/db.toml. It has a schema tree, a query editor with completion and schema docs, a result grid, and cell edits when a query returns the table's primary key. Every write is shown and confirmed before it runs.

      TerminalAlt+T

      Your own shell, started in the project root. It keeps running in the background while you edit, so Alt+T returns to the same session.

      SQL anywhereAlt+Enter

      Run the SQL statement under the caret in any file and inspect the result in a popup, without switching views.

      .sanitty/db.toml

      Databases from your compose file

      The Database view reads docker compose config and picks up PostgreSQL and MySQL/MariaDB services by their image or their POSTGRES_*, MYSQL_* and MARIADB_* variables. A project with a database in compose needs no setup.

      To change a service or add a connection, such as a remote server or a SQLite file, put it in .sanitty/db.toml in the project. Passwords can come from an environment variable.

      Your queries are kept per connection in ~/.local/state/sanitty/, not in the project. table_rows and max_rows in settings.toml set how many rows a table or a result shows.

      # .sanitty/db.toml
[connections.db]       # the compose service "db"
port = 5433

[connections.reports]
url = "postgres://reader@reports.internal/reports"
password_env = "REPORTS_PASSWORD"

[connections.local]
path = "db.sqlite3"     # SQLite, relative to the project

      ~/.config/sanitty/

      Keys and settings

      sanitty reads its configuration from $XDG_CONFIG_HOME/sanitty, which is ~/.config/sanitty by default. Shortcuts go in keymap.toml and everything else in settings.toml.

      Every setting is optional and takes effect when sanitty starts. If a line has a mistake, sanitty shows it in the status line and falls back to the default.

      # keymap.toml: move Go to Definition to F12
[bindings]
"f12"   = "goto-definition"
"alt+b" = "none"
      # settings.toml
[editor]
tab_size = 4          # spaces Tab inserts

[python]
server = "ty"         # ty, basedpyright, pyright or pylsp
ruff = true           # lint warnings and formatting

[database]
table_rows = 500      # rows when opening a table
max_rows = 10000      # rows a result keeps

      install.sh

      Install

      Static binaries for Linux on amd64 and arm64, so any distribution works.

      curl -fsSL https://apt.tileception.space/setup.sh | sudo sh
sudo apt install sanitty

      Debian and Ubuntu. The first line adds the Tileception apt repository and its signing key, and you can read it first. After that, sudo apt upgrade picks up new versions.

      Add the repository by hand

      These are the steps the script runs. The keyring package keeps the signing key up to date afterwards.

      curl -fsSL https://apt.tileception.space/tileception.gpg | sudo install -D -m 644 /dev/stdin /usr/share/keyrings/tileception-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/tileception.sources <<SRC
Types: deb
URIs: https://apt.tileception.space
Suites: $(. /etc/os-release; echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: main
Signed-By: /usr/share/keyrings/tileception-archive-keyring.gpg
SRC
sudo apt update && sudo apt install tileception-archive-keyring sanitty
      cargo binstall sanitty

      Downloads the release binary. Run it again to upgrade.

      cargo install sanitty

      Builds from crates.io. Needs Rust 1.100 or newer and a C compiler for the Tree-sitter parsers.

      $ sanitty /path/to/project
$ sanitty z project      # the directory zoxide knows as "project"

      Language servers are optional and installed separately on the machine running sanitty. Source on GitHub, crate on crates.io.
